# Eden – Boutique en ligne

Site vitrine de la boutique **Eden** (bijoux, tech, déco) avec panier et commande via WhatsApp.

## Structure

```
├── index.html          # Page principale
├── css/style.css       # Styles
├── js/script.js        # Produits, panier, navigation
└── images/
    ├── logo.png
    ├── hero.jpeg       # Image de la page d'accueil
    ├── produits/       # Photos des produits affichés
    └── a-venir/        # Photos pas encore utilisées sur le site
```

## Ajouter un produit

1. Mettre la photo dans `images/produits/` (nom en minuscules, sans espaces).
2. Ajouter une ligne dans le tableau `products` en haut de `js/script.js`.

## Mise en ligne

Hébergé avec GitHub Pages : *Settings → Pages → Branch `main` / dossier `/ (root)`*.
